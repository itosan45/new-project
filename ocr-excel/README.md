# 画像・PDF → Excel 自動入力

手書きの書類やPDFを読み取って、決めた項目をExcelの決めた列に自動で入れる仕組み。

**APIの鍵や面倒な認証設定は一切いりません。** すでにつながっている
Google Driveの文字読み取り機能をそのまま使います。

## 使い方

1. 読み取りたい画像・PDFを、**Google Driveのどこかのフォルダに入れる**
   (スマホで撮った写真をそのままDriveに保存すればOK)
2. 秘書(Claude)に「Driveの○○フォルダの書類をExcelに取り込んで」と頼む
3. 秘書がDriveから文字を読み取り、`抽出結果.xlsx` に1枚1行で書き込む

2回目以降は、既存のExcelの下に追記されていきます。

## 抽出する項目・入れる列を変えたいとき

`設定.yaml` を書き換えるだけです。プログラム本体はさわらなくて大丈夫です。

```yaml
項目:
  - 列: A            # Excelのどの列に入れるか
    見出し: ファイル名  # 1行目に表示する名前
    種類: ファイル名    # 何を取り出すか
```

「種類」に指定できるもの:

| 種類 | 意味 |
|---|---|
| ファイル名 | 元の画像のファイル名 |
| 日付 | 文書内の日付(令和表記も西暦に変換) |
| 金額 | ¥1,234 や 1,234円 など。複数あれば一番大きい額(=合計とみなす) |
| 電話番号 | 03-1234-5678 など |
| 全文 | 読み取った文字すべて |
| キーワード | 指定した言葉の右または下にある値。`手がかり:` で言葉を指定 |

「キーワード」の例(「宛名」「様」などの近くにある名前を拾う):

```yaml
  - 列: D
    見出し: 宛名
    種類: キーワード
    手がかり: [宛名, 様, お名前, 氏名]
```

宛名として拾った値の末尾の「様」「御中」などは自動で取り除かれます。

## 動作確認

```bash
python3 テスト.py
```

## 中の仕組み(参考)

- `lib/抽出.py` … 読み取った文字から日付・金額などを取り出す
- `lib/エクセル.py` … Excelへの書き込み・追記
- `取り込み.py` … 読み取り結果をまとめてExcelに流し込む(秘書が使う)
- `設定.yaml` … どの項目をどの列に入れるかの設定
