# 画像・PDF → Excel 自動入力

手書きの画像やPDFを読み取って、決めた項目をExcelの決めた列に自動で入れる仕組み。

## できること

- `入力画像/` フォルダに画像やPDFを入れて実行すると、まとめて読み取る
- 読み取った文字から「日付」「金額」「宛名」「電話番号」などを取り出す
- `抽出結果.xlsx` の決めた列に、1枚1行で書き込む(2回目以降は下に追記)
- 処理が終わった画像は `処理済み/` に移動する

## 使い方

```bash
cd ocr-excel
python3 実行.py
```

## 抽出する項目・入れる列を変えたいとき

`設定.yaml` を書き換えるだけです。プログラム本体はさわらなくて大丈夫です。

```yaml
項目:
  - 列: A            # Excelのどの列に入れるか
    見出し: ファイル名  # 1行目に表示する名前
    種類: ファイル名    # 何を取り出すか
```

「種類」に指定できるもの:

| 種類 | 意味 |
|---|---|
| ファイル名 | 元の画像のファイル名 |
| 日付 | 文書内の日付(令和表記も西暦に変換) |
| 金額 | ¥1,234 や 1,234円 など。複数あれば一番大きい額(=合計とみなす) |
| 電話番号 | 03-1234-5678 など |
| 全文 | 読み取った文字すべて |
| キーワード | 指定した言葉の右または下にある値。`手がかり:` で言葉を指定 |

## 準備(最初の1回だけ)

Google Cloud Vision API を使うので、鍵ファイルが必要です。

1. https://console.cloud.google.com/ を開く
2. プロジェクトを作る(名前は何でもよい)
3. 「Cloud Vision API」を検索して有効にする
4. 「サービスアカウント」を作り、鍵(JSONファイル)をダウンロードする
5. ダウンロードした鍵ファイルの場所を、環境変数に設定する

```bash
export GOOGLE_APPLICATION_CREDENTIALS="鍵ファイルの場所/xxxxx.json"
```

料金は月1,000枚まで無料、それ以降は1,000枚あたり約1.5ドルです。

## 動作確認

Vision APIを使わない部分(項目の取り出し・Excel書き込み)は、
鍵がなくても無料でテストできます。

```bash
python3 テスト.py
```
