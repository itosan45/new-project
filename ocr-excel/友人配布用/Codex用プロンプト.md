# Codexで使う(自分のパソコンで動かす・大量処理向き)

ChatGPT版と違って、一度セットアップすれば**毎日フォルダに画像を放り込むだけ**に
できます。枚数が多い人向け。

## 貼り付けるプロンプト

Codexに下の四角の中をまるごと貼り付けてください。

```
書類の画像をExcelに転記するツールを作ってください。

【作るもの】
- スキャン画像を入れる「入力」フォルダ
- 転記.py … 読み取り結果のJSONを受け取り、Excelに1件1行で書き込む
  (同梱の 転記.py をそのまま使ってよい。仕様は下記)
- 読み取りは、パソコンにインストールしたOCRエンジンで行う
  日本語の手書きに対応させたいので tesseract の日本語データ(jpn)を使う
  例: pip install pytesseract pillow / apt install tesseract-ocr tesseract-ocr-jpn

【転記.pyの仕様(すでに実装済み・変更不要)】
入力: [{"ファイル名": "...", "全文": "..."}] という形のJSONファイル
出力: 抽出結果.xlsx に1件1行で追記
抽出する項目:
  A ファイル名
  B 日付   … 令和表記も西暦に変換する
  C 金額   … ¥1,234 / 1,234円 の形。複数あれば最大値を合計とみなす
  D 宛名   … 「宛名」「お名前」「氏名」の近くの値。末尾の敬称は除去
  E 電話番号
  F 読み取り全文
列の構成は 転記.py の冒頭「設定」を書き換えるだけで変えられる

【つなぎ込み】
入力フォルダの画像をOCRにかけ、上のJSON形式にして 転記.py に渡す
実行スクリプトを1本作ってください。処理済みの画像は別フォルダに移動する。

【お願い】
- 依存パッケージはできるだけ少なくしてください
- 読み取れなかった項目は推測で埋めず空欄にしてください
- 抽出まわりにはテストをつけてください
```

このプロンプトと一緒に、同じフォルダにある **転記.py** を渡してください。
中核部分はすでに動作確認済みなので、Codexはつなぎ込みだけを作ればよくなります。

## tesseract を使わず、より高精度にしたい場合

プロンプト内の「読み取りは〜」の部分を、下のどちらかに差し替えてください。

- **Google Cloud Vision API を使う**(高精度・手書きに強い。ただし
  Googleアカウントの設定と鍵の発行が必要。従量課金だが少量なら無料枠内)
- **画像をChatGPTに読ませる**(設定不要。枚数が少ないならこちらが楽)
