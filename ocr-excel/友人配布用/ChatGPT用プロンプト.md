# ChatGPTで使う(インストール不要・一番かんたん)

ChatGPTは画像を読めて、Pythonも動かせます。だから**何もインストールせずに**
写真からExcelを作れます。

## やること

1. ChatGPTの新しいチャットを開く
2. 下の四角の中を**まるごとコピーして貼り付ける**
3. 同じメッセージに、書類の写真を何枚でも添付する
4. 送信 → Excelファイルが返ってくる

以上です。毎日これだけです。

---

## 貼り付けるプロンプト

```
添付した書類の画像を読み取って、Excelファイルを作ってください。

【手順】
1. 各画像の文字をすべて読み取る(手書きも含む)
2. 画像ごとに次の項目を取り出す
   - ファイル名
   - 日付(令和表記なら西暦に直す。例: 令和8年8月14日 → 2026-08-14)
   - 金額(¥1,234 や 1,234円 の形。複数あれば一番大きい額を合計とみなす)
   - 宛名(「宛名」「お名前」「氏名」の近くの名前。末尾の「様」「御中」「殿」は取り除く)
   - 電話番号
   - 読み取った全文
3. Pythonのopenpyxlを使って、1画像=1行のExcelを作る
   - 列は左から順に A:ファイル名 B:日付 C:金額 D:宛名 E:電話番号 F:読み取り全文
   - 1行目は見出し
   - シート名は「抽出データ」
   - ファイル名は 抽出結果.xlsx
4. できあがったExcelファイルをダウンロードできる形で渡す

【守ってほしいこと】
- 読み取れなかった項目は、推測で埋めずに空欄にする
- 数字は勝手に整形しない(金額はカンマなしの数字だけ)
- 読み取りに自信がない箇所があれば、Excelとは別に文章で教えてください
```

---

## 2回目以降、前のExcelに追記したいとき

前回のExcelファイルも一緒に添付して、プロンプトの最後にこの1行を足してください。

```
添付した既存の抽出結果.xlsxの一番下に追記する形で作ってください。
```

## 列を増やしたい・変えたいとき

プロンpt内の「2.」の項目リストと「3.」の列の並びを、好きなように書き換えるだけです。
たとえば「担当者」を足したいなら、項目に「担当者(「担当」の近くの名前)」を追加して、
列に `G:担当者` を足します。
