# 書類 → Excel 転記ツール(配布用)

手書きの伝票や領収書の写真から、日付・金額・宛名などを取り出して
Excelに1枚1行で並べるツールです。

## どれを使えばいい?

| 使う人 | 見るファイル | 準備 |
|---|---|---|
| ChatGPTを使っている | `ChatGPT用プロンプト.md` | **なし**。貼り付けて写真を添付するだけ |
| Codexでパソコン上に組みたい | `Codex用プロンプト.md` + `転記.py` | Python と openpyxl |

枚数が少ないなら ChatGPT版が圧倒的に楽です。毎日何十枚も処理するなら
Codex版でフォルダ監視まで作るのがおすすめです。

## 転記.py について

1ファイルで完結しています。必要なのは `openpyxl` だけです。

```bash
pip install openpyxl
python3 転記.py 読み取り結果.json
```

`読み取り結果.json` の形:

```json
[
  {"ファイル名": "領収書01.jpg", "全文": "領収書\n2026年8月14日\n合計 ¥4,950"}
]
```

取り出せる項目と入れる列は、`転記.py` の冒頭にある「設定」を書き換えるだけで
変えられます。それより下は触らなくて大丈夫です。

### できること

- 日付 … `2026年8月14日` `2026/8/14` `令和8年8月14日` などを `2026-08-14` に統一
- 金額 … `¥4,950` `4,950円` を数字だけに。複数あれば一番大きい額(=合計)を採用
- 宛名 … 「宛名」「お名前」などの右または次の行。末尾の「様」「御中」は自動で除去
- 電話番号
- 2回目以降は既存のExcelの下に追記
