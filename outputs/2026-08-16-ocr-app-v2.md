`ocr-app/` の読み取りエンジンをClaude APIからGemini API(gemini-2.5-pro)に
差し替えた。

- `app/api/ocr/route.ts` … `@google/genai` を使用。画像/PDFは `inlineData`
  で渡し、`responseMimeType: "application/json"` + `responseJsonSchema` で
  項目抽出を保証(スキーマ・プロンプトの内容はv1から変更なし)。
  `finishReason`(SAFETY/PROHIBITED_CONTENT/MAX_TOKENS等)と `ApiError`
  (ステータスコード)でエラーハンドリング
- `.env.example` / `README.md` … `GEMINI_API_KEY` とGoogle AI Studio
  (aistudio.google.com/apikey)での取得手順に更新
- UI(`app/page.tsx`)・CSV出力・認証(`proxy.ts`/`lib/auth.ts`)は変更なし

`npm run build`(型チェック込み)と `npm run lint` を確認済み。
実写真での通しテストはAPIキー設定後にユーザーが実施。
