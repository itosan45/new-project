`ocr-app/` に構築。Next.js 16(webappと同スタック)+ Claude API(claude-opus-5)。

- `app/page.tsx` … 撮影/ファイル選択 → クライアント側で長辺2576pxに縮小 →
  読み取り結果の項目表示 → CSVダウンロード(BOM付きUTF-8、1枚=1行)
- `app/api/ocr/route.ts` … Claude APIのvision + structured outputs で
  書類の種類・日付・金額・宛名・電話番号・全文・読み取りメモを抽出。
  崩れた手書きは文脈から推測、読めない箇所は「?」+メモに候補を記載
- `proxy.ts` / `lib/auth.ts` … webappと同じ1パスワード+HMAC Cookie認証
- PDF(4MBまで)対応。Vercelに Root Directory = `ocr-app` でデプロイする

`npm run build`(型チェック込み)と `npm run lint` を確認済み。
実写真での通しテストはAPIキー設定後にユーザーが実施(手順は `ocr-app/README.md`)。
