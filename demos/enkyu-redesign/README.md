# 遠州急行 デザイン案（非公式・試作）

株式会社遠州急行（https://enkyu.co.jp/）のホームページを、
デザインをブラッシュアップしたらどうなるかの試作。

**公式サイトではありません。** ページの先頭にその旨を出してある。
`<meta name="robots" content="noindex, nofollow">` も入れてある。
掲載内容は公開情報のみで、勝手に作った実績や数字は入れていない。

## 元サイトから拾ったもの

- キャッチ「55年分の誠実」「柔軟対応・遠州急行」
- サービス: 物流（NEW CHARTER便・中継輸送）／コンサルテーション／倉庫／安全への取り組み
- 所在地・電話・FAX・フリーダイヤル・営業時間
- ブランドの青（#0b58cc）

## 変えたところと、その理由

| 変えたこと | 理由 |
|---|---|
| 主導線を**電話1つ**に絞り、全画面の上下とスマホ下部に固定 | 運送は電話が主導線。受付時間を必ず横に書く（時間外にかけて出ないと、その1件は二度と来ない） |
| 冒頭を「断られてきた荷物ほど」に | 相手の困りごとから入る。会社紹介から始めると、見た人が何もせずに帰る |
| 中継輸送を独立した見せ場にし、図で説明 | 同業者向けの差別化要素。文章だけだと伝わらない |
| 明朝の大見出し＋紙色の地 | 55年の会社。角ゴ＋白背景だと新興のIT企業に見える |
| ご依頼の流れを4段階の図に | 初めての人の不安を先に消す |

## 技術的なこと

- 単一のHTMLファイル。外部読み込みなし
- **フォントは使う文字だけ埋め込み**（約300KB）。回線が細い現場でも同じ見た目で出る
- 画像なし。図・ロゴ・Gマークは全部SVGとCSSで描いてある（素材の権利問題が起きない）
- スマホ390px／PC1280pxで確認済み。横スクロールなし
- 動きは控えめ（スクロールで出る、点線が流れる）。`prefers-reduced-motion` で止まる

## この試作でやっていないこと

- 写真が1枚もない。実際のサイトには現場・車両・人の写真が要る
- 各下層ページ（業務案内の詳細、採用、問い合わせフォーム）は作っていない
- 元サイトの実際の見た目は確認できていない（この環境のブラウザから接続できず、
  HTMLとCSSのみ取得した）
