# 2026-08-17

- ai-fishing-advisor で「実データ・推定・ダミー値の棚卸し」を行った。
  表示している値を A(実API) / B(AI推定) / C(数式) / D(ダミー) /
  E(永続保存) / F(保存されているように見えて保存されない) で分類し、
  誤解を招くものから順に直した。

- 潮汐を気象庁の実データに置き換えた。それまでは緯度経度から作った
  サイン波で、実際の潮とは無関係な数字を潮位表の顔で出していた。
  気象庁は年間の潮位表を無料・APIキーなしで公開している。

- この置き換えで、それまで気づいていなかった不具合が3つ出た。
  いずれも「エラーにならず静かに効かない」形だったため、
  画面を見ているだけでは分からなかった。
  1. 時刻が "8:00" 形式で Date として解釈できず、釣果の潮回り
     （上げ◯分）が本番で一度も記録されていなかった。
  2. 潮の動き出し通知が、時ではなく年を読んでいて一度も鳴らなかった。
  3. 気象庁のサーバーは CORS ヘッダを返さないため、端末から直接
     取りに行くとブラウザでだけ必ず失敗する。

- 学び: 3つ目は Node の検証では 28/28 通っていた。**検証条件そのものが
  不具合を隠す**ことがある。以前、単色のテスト映像で文字の視認性が
  合格に見えていたのと同じ構図だった。以後、端末で動くものは
  実際のブラウザまで通して確かめる。

- AIの推定値（活性スコア等）に confidence（確度・根拠・分からなかった点）を
  必須で返させるようにした。写真1枚からの推定でも2桁で出ると計測値に
  見えるため。確度が低いときは断定色をやめる。

- 保留: 集合知の共有保存（Google スプレッドシート + サービスアカウント）。
