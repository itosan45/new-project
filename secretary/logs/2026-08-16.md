# 2026-08-16

- OCRの認識精度について質問を受けた。回答の要点: 事務機スキャナーの方が
  照明・歪み・解像度の面で有利。スマホはスキャン専用アプリ(台形補正・
  二値化あり)を使えば実用水準。手書き・低コントラスト原稿は事務機が明確に有利。
- 「下手な手書きでも読み取れる内製OCRアプリ」の構築依頼を受けた。
  ベンチマークは DocumentForce(https://lp.documentforce.ai/)。
  engineer 部署で `ocr-app/` を構築。方式はユーザーに確認のうえ
  Claude API のvision機能を採用(decisions/2026-08-16-ocr-use-claude-api-vision.md)。
  出力は画面表示+CSVダウンロード。
- 「OCRのAPIはGoogleのVision APIでもいいか」という質問を受けた。回答:
  Vision APIは従来型OCRで、活字は得意だが崩れた手書きの文脈推測ができず、
  項目抽出も自作が必要。DocumentForce級の手書き精度はLLMのvision
  (Claude / Gemini)によるもの。Google系で揃えるなら正解はGemini API。
  API呼び出しは ocr-app/app/api/ocr/route.ts に隔離してあり差し替えは容易。
  現状はClaude APIのまま継続。
