## 決めたこと

画像・PDFの文字読み取りに、Google Cloud Vision API ではなく、
すでに認証済みの Google Drive の読み取り機能を使う。

## 理由

Vision API を使う場合、Google Cloud アカウント作成・API有効化・
サービスアカウント鍵の発行・支払い情報登録という長い手動セットアップが
必要になる。実際に着手したところ、この認証作業が大きな負担になった。

一方、Google Drive はすでにこのセッションと接続済みで、画像・PDFに対して
文字読み取りが標準で効く。実データ(スキャン画像)で検証したところ、
日本語の文章を問題なく読み取れた。

同じ結果が得られるなら、セットアップ不要な方を選ぶ。

## 影響

- 利用者側の準備作業がゼロになった
- 代わりに、読み取りは秘書(Claude)経由になる。完全な無人自動処理はできない
