# いま受けられる仕事

2026-08-19 時点。できないことも同じ重さで書く。
できることの一覧しか無いと、守備範囲の外の仕事を受けて事故る。

## 実働部隊は2つある。中身がぜんぜん違う

### 1. 秘書（Claude）とあなた ← いま実際に手が動くのはここ

これが今の実働部隊。設計・実装・調査・文章・デザイン・デプロイまで、
実際に成果物が出ます。このリポジトリ自体がその成果物です。

すでに作ったもの:

| もの | 中身 |
|---|---|
| 業務自動化ハーネス | Next.js 16 + TypeScript。ログイン・案件管理・承認・保存 |
| OCR→Excel | 手書き画像から日付・金額・電話番号を抜いてExcelへ転記（Python、動く） |
| つながりの地図 | リポジトリ全体を読んでグラフを作る仕組み |
| 友人配布用の転記ツール | 単一ファイルのPython + 使い方プロンプト |

### 2. ハーネスの Agent 25体 ← 5体だけ動く

Web制作の役割分担Agent 5体（ヒアリング設計・情報設計・見積根拠・計測設計・
公開前チェック）は**実際に動きます**。入力が足りなければ、それらしい出力を出さずに
「何が足りないか」を言って止まります。

残り20体は契約（何をしてよいか）を決めた段階で、中身はありません。
画面でも「契約だけ」と表示され、案件を流すと「中身なし」として記録されます。
**やっていないことを完了と表示しない**ようにしてあります。

順序の問題です。中身の精度は後から差し替えられますが、
「承認せずに送ってしまった」「記録が無いから説明できない」は後から直せません。
だから先に枠を作りました。

**なので今の答えとしては、仕事を受けるのは1の体制です。**

## 侵襲度で分けた、受けられる仕事

一人で回している間は **L2 まで**。

### L0 — 相手のシステムに触らない ★いちばん受けやすい

事故っても影響が自社内で収まります。

- **ホームページ・LP制作**（→ 下に詳しく）
- 記事・ブログ・メルマガの作成
- SNS運用（投稿案の作成、投稿カレンダー）
- 業界調査・競合調査レポート
- 提案資料・営業資料・図解の作成
- 動画の構成・台本
- 社内向けマニュアル、手順書

### L1 — 相手のファイルを読むだけ

読むだけなので相手のデータは壊れません。

- 手書き書類・領収書・請求書・調査票のデータ化（**実物が動きます**）
- もらったExcel・CSVの集計・分析・グラフ化
- 大量の問い合わせ文の分類・傾向出し
- PDFの中身の抽出・要約

### L2 — 相手のファイルに書く

元ファイルが壊れうるので、バックアップと承認が要ります。

- 読み取った内容を、指定のExcelのセルへ転記
- スプレッドシートの定期更新
- 定型の書類（見積書・報告書）の自動生成

### L3以上 — 一人のうちは受けない

会計ソフトや基幹システムへの書き込み、業務フローそのものの置き換え。
事故ったときに直せる人間があなたしかいない状態で、相手の業務を止めることになります。
実績と、直せる体制ができてからです。

## 「ホームページ作ってください」— できます

L0 なので、いちばん受けやすい種類の仕事です。

### できること

| 工程 | 中身 |
|---|---|
| ヒアリング | 6段階の「相談」。何のためのHPか、誰に見せるかを詰める |
| 構成 | ページ構成、載せる内容、導線 |
| デザイン | 画面デザイン。Figmaでも、コードで直接でも |
| 実装 | Next.js / 素のHTML。スマホ対応込み |
| 文章 | キャッチコピー、本文、事業説明 |
| 図 | 図解・アイコン（コードで描くので追加費用なし） |
| 公開 | Vercel、または WordPress.com へ |
| 問い合わせフォーム | 設置できる（送信先の設定はあなたの操作が要る） |
| 更新 | あとから直せる形で渡す |

WordPress.com なら、サイト作成・記事投稿・独自ドメインの空き確認と
料金確認・支払いページの発行まで、こちらで進められます。
**支払いだけはあなたが押します。**

### できないこと

- **独自ドメインの購入手続きそのもの**（支払いはあなた）
- **DNSの設定**（管理画面のログインが要る。ログイン情報は預かりません）
- **写真の撮影**（素材の用意はあなたか、フリー素材）
- **相手のサーバーへのFTP納品**（認証情報を預かれない）
- ロゴの商標登録などの法的手続き
- SEOで上位に出ることの保証

### 決めること（18項目）

「ホームページ作って」だけでは発注になりません。ハーネスの `/web` に全部並べてあります。

**1回目に聞くこと（10項目）**
狙い / 見る人 / してほしい行動 / 今あるサイト / 置き場所 / 独自ドメイン /
雛形か作り込みか / いまの件数 / 公開希望日 / 予算

**2回目以降（7項目）**
ページ / 文章と写真の担当 / 動き・動画 / SNS / 公式LINE / チャット / 公開後の更新

**制作前（1項目）**
問い合わせフォームの送信先

このうち**8項目は、決まらないと見積が出せません**。
Agentも、未回答のままでは見積も構成も出さずに止まります。

### 関係する部署

- `web-designer` 画面デザイン・UI/UXの判断
- `engineer` 実装・技術的な判断
- `creator` 文章・コンテンツ

## 受けないほうがいい仕事

- 相手の基幹システムに書き込むもの（L3以上）
- 24時間の障害対応が要るもの（一人なので受けられない）
- 説明できない判断をAIに任せるもの（医療・法務の最終判断など）
- 承認待ちが5件溜まっている時期の新規案件

## 最初の一歩

仕事の話が来たら、`/flow` の「相談」から入れてください。
何を聞けばよいか、次に進める条件は何かが書いてあります。
